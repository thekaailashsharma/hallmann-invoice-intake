# n8n workflows

These are the five n8n workflows behind the invoice intake. The easiest way to import them is `scripts/setup.sh`. It creates the credentials from your `.env`, imports the workflows, switches them on and puts them in a folder called "Hallmann · Invoice Intake". If you prefer, you can also import each file by hand in n8n under Workflows, Import from file.

`01-invoice-intake.json` watches the invoice mailbox. It saves every email and its attachments first, then hands each email over to be processed. `02-process-email.json` does the actual work: it reads the PDF or XML, checks the text for manipulation, lets the AI read the fields and then runs the rules that decide what happens. `03-erp-booking.json` is the only workflow that writes to the ERP, and it keeps retrying when the ERP is down. `04-review-decision.json` takes the decisions Jana and Thomas make on the review screen. `05-monitoring.json` sends Avanai an email when something fails or gets stuck.

The files contain no passwords or keys. You will need credentials for Postgres, an OpenAI-compatible AI provider, the mailbox (IMAP and SMTP), the shared webhook key, the ERP key, and Gmail if you use it.

Please don't edit these files by hand. They are generated by `scripts/build-workflows.py`, so change the generator and then run it again together with `scripts/import-workflows.py`.
