# n8n workflows

Exported n8n workflows (n8n 2.x). Import them with `scripts/setup.sh` (creates the credentials from `.env`, imports, publishes, files them into the folder "Hallmann · Invoice Intake"), or by hand in n8n: **Workflows → Import from file**, then attach the credentials listed below.

| File | Workflow | Trigger | Job |
|---|---|---|---|
| `01-invoice-intake.json` | Invoice Intake | IMAP / Gmail mailbox | Store every email and its files first, label Gmail mail "Processed", hand each email to Process Email |
| `02-process-email.json` | Process Email | called per email | Read PDFs/XML, guardrails, AI classify + extract, rules decide, save, book |
| `03-erp-booking.json` | ERP Booking | called + every 5 min | Real-time ERP API call, retry when the ERP is down, alerts |
| `04-review-decision.json` | Review Decision | webhook from the review screen | Approve / save / reject / reopen with role check, same rules, audit log |
| `05-monitoring.json` | Monitoring | workflow errors + every 15 min | One alert per problem, e-mail to Avanai on-call, re-run stuck emails |

**Credentials** (none are stored in these files): Postgres · OpenAI-compatible LLM · IMAP · SMTP · header auth for the webhooks · header auth for the ERP API · Gmail OAuth2 (optional).

**Do not edit these files by hand.** They are generated by `scripts/build-workflows.py` (stable ids, the shared validator embedded byte-identical, a test checks it). Change the generator, then run `python3 scripts/build-workflows.py && python3 scripts/import-workflows.py`.
