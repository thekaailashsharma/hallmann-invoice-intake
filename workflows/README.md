# n8n workflows

These are the five workflows, exported from n8n 2.x. Import them with `scripts/setup.sh`. It creates the credentials from `.env`, imports the workflows, publishes them and puts them in the folder "Hallmann · Invoice Intake". You can also import them by hand: Workflows, then Import from file.

1. `01-invoice-intake.json`, Invoice Intake: reads the mailbox, stores every email and its files, then hands each email on.
2. `02-process-email.json`, Process Email: reads the PDF or XML, runs the manipulation check, the AI and the rules, then saves and books.
3. `03-erp-booking.json`, ERP Booking: books in the ERP and retries every 5 minutes when it is down.
4. `04-review-decision.json`, Review Decision: handles the decisions made on the review screen.
5. `05-monitoring.json`, Monitoring: alerts Avanai when something fails or gets stuck.

No credentials are stored in these files. You need: Postgres, an OpenAI-compatible LLM, IMAP, SMTP, a header key for the webhooks, a header key for the ERP, and Gmail if you use it.

Don't edit these files by hand. They are generated by `scripts/build-workflows.py`. Change the generator, then run it and `scripts/import-workflows.py`.
